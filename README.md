# N8N-HW1.2

یک ماشین حساب کنسولی ساده برای جمع، تفریق، ضرب و تقسیم.

## اجرا

برای اجرای برنامهٔ کنسولی با .NET 8:

```bash
dotnet run
```

در زمان اجرا یکی از عملیات زیر را وارد کنید:

- `جمع` یا `add`
- `تفریق` یا `subtract`
- `ضرب` یا `multiply`
- `تقسیم` یا `divide`
- `خروج` یا `exit`

همچنین می‌توانید برای ضرب و تقسیم از نمادهای `*` و `/` استفاده کنید.

سپس دو عدد را وارد کنید تا نتیجه نمایش داده شود. تقسیم بر صفر با پیام خطا رد می‌شود و برنامه به دریافت عملیات ادامه می‌دهد.
