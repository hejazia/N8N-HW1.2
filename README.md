# N8N-HW1.2

یک ماشین حساب کنسولی ساده برای جمع، تفریق، ضرب، تقسیم و فاکتوریل.

## اجرا

برای اجرای برنامهٔ کنسولی با .NET 8:

```bash
dotnet run
```

در زمان اجرا یکی از عملیات زیر را وارد کنید:

- `جمع` یا `add`
- `تفریق` یا `subtract`
- `ضرب` یا `multiply`
- `تقسیم` یا `divide`
- `فاکتوریل` یا `factorial`
- `خروج` یا `exit`

همچنین می‌توانید برای ضرب و تقسیم از نمادهای `*` و `/` و برای فاکتوریل از نماد `!` استفاده کنید.

برای عملیات جمع، تفریق، ضرب و تقسیم، دو عدد وارد کنید. برای فاکتوریل، یک عدد صحیح نامنفی وارد کنید؛ مقدار `0!` برابر `1` است. تقسیم بر صفر و فاکتوریل اعداد منفی با پیام خطا رد می‌شوند و برنامه به دریافت عملیات ادامه می‌دهد.
